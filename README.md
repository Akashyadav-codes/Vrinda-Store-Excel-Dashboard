# 📊 Vrinda Store Annual Report 2022 Dashboard

## 📌 Project Overview

This project presents an interactive Excel dashboard built using Vrinda Store's 2022 sales dataset. The dashboard helps analyze sales performance, customer behavior, order status, and channel effectiveness.

---

## 🎯 Objectives

- Analyze annual sales performance
- Identify top-performing states
- Compare sales by gender and age group
- Track order status
- Evaluate sales channels
- Generate business insights for decision-making

---

## 🛠️ Tools & Techniques Used

- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers
- Data Cleaning
- Data Visualization
- Dashboard Design

---

## 📈 Dashboard Features

### Sales vs Orders Analysis
- Monthly sales trend
- Monthly order trend

### Customer Demographics
- Men vs Women purchases
- Age group analysis

### Order Status Analysis
- Delivered orders
- Cancelled orders
- Returned orders

### State-wise Performance
- Top states by sales

### Channel Performance
- Amazon
- Flipkart
- Myntra
- Ajio
- Other channels

---

## 📊 Key Insights

- Women contributed the majority of sales.
- Adult age group generated the highest revenue.
- Most orders were successfully delivered.
- Maharashtra was among the top-performing states.
- Amazon generated the highest number of orders.
